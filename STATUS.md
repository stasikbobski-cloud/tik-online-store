## Не реализовано (не отмечать как готовое)

Согласно ТЗ §26, статус следующих функций подтверждён как **НЕ ГОТОВО**:

1. **Импорт 10 000+ товаров OPTOM1** — ❌. Ни API, ни XML/CSV-выгрузка не подключены. Товары во фронтенде — фиксированный демо-массив (`products` в index/catalog/cart/account/favorites.html) с вымышленными ценами, рейтингами и отзывами. По ТЗ §1 п.1–2 это недопустимо в «боевом» виде.
2. **Автоматическая синхронизация остатков** — ❌. Остатки нигде не отображаются и не проверяются; серверной части нет.
3. **Генерация отсутствующих изображений нейросетью** — ❌.
4. **Улучшение существующих изображений нейросетью** — ❌.
5. **Серверная регистрация по e-mail / подтверждение адреса / восстановление пароля** — ❌. Форма кабинета — только интерфейс.
6. **Вход через VK** — ❌.
7. **Серверное хранение корзины и избранного** — ❌ (только localStorage).
8. **Создание и хранение заказов** — ❌. Оформление заказа не реализовано.
9. **Платежи** — ❌ (по ТЗ — последний этап).
10. **Административные инструменты** (ТЗ §21) — ❌ полностью отсутствуют.

## Технические ограничения текущего кода

- Нет единого товарного слоя: массив `products` дублируется в 5 HTML-файлах. Перед импортом OPTOM1 необходим общий модуль данных (`shared-products.js` или серверный API).
- Нет страниц карточек товаров (ТЗ §7) — клик по товару не ведёт на детальную страницу.
- Нет пагинации/виртуализации (ТЗ §6 «Масштабирование») — при реальном каталоге 10 000 позиций текущий рендер неприменим.
- Поиск работает только по демо-массиву.
- Фотографии витрины — стоковые (unsplash), не реальные фото товаров поставщика.

## Результаты разведки поставщика (проверено 2026-10-19 запросами)

- `https://optom1.ru/` отвечает (200), публичный каталог существует (`/catalog/...`).
- `robots.txt`: разрешена индексация всего, кроме `/catalog/elektronnye_ispariteli/`, указан `Crawl-delay: 3` и sitemap.
- `https://optom1.ru/sitemap.xml` возвращает страницу «Не найдена» — карта сайта недоступна по этому адресу.
- Публичных ссылок на XML/CSV/XLSX прайс-лист или API на главной не обнаружено. Вероятно, выгрузка выдаётся в личном кабинете оптовика после регистрации.
- **Вывод:** автоматический парсинг сайта без согласования нарушает условия доступа (ТЗ §8). Следующий шаг — зарегистрироваться у OPTOM1 и запросить официальный способ выгрузки (прайс XML/API). До получения данных витрина не должна показывать цены/остатки как реальные.

## Ближайшие этапы (по порядку ТЗ §24)

1. **Этап 5 (начало):** получить у OPTOM1 официальный прайс (регистрация оптовика → выгрузка XML/CSV/API). Альтернативы парсинга не использовать без разрешения поставщика.
2. Создать единый модуль данных товара + генератор статических карточек товаров (product.html?id=...) либо план серверной части.
3. Заменить демо-массив на импорт (хотя бы первой партии) с полями: id, артикул, название, категория, цена, остаток, фото.
4. Только после этого — синхронизация остатков (§10), затем AI-фото (§9), затем аккаунт/заказы на сервере (§13–14), платежи в последнюю очередь (§24, этап 8).
