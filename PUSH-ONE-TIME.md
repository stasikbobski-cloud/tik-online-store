# Одно действие, которое нужно сделать тебе (2 минуты)

Я всё подготовил: ветка `main` в проекте уже содержит все последние изменения
(выравнивание шапки, единое меню, фавикон, аудит STATUS.md, инструкции).
Остался единственный шаг — **разрешить мне отправить это в твой GitHub**.
Без твоего разрешения GitHub меня не пустит (это защита твоего аккаунта,
обойти её нельзя — и не надо).

## Делаем один раз

1. Открой ссылку: https://github.com/settings/tokens/new?description=tik-push&scopes=repo
   (если попросит — войди в свой аккаунт stasikbobski-cloud).
2. Страница "Personal access tokens (classic)":
   - Note (имя): `tik-push` — можно не менять.
   - Expiration: выбери **90 days**.
   - Галочки scopes: должна быть одна отмеченная — **repo** (она уже отмечена по ссылке выше).
3. Нажми зелёную кнопку **"Generate token"** внизу страницы.
4. Появится токен — длинный набор букв/цифр, начинается с `<твой токен>`.
   Скопируй его целиком (он показывается только один раз).
5. Пришли мне этот токен сюда, одним сообщением. Всё.

Дальше я сам:
- сохраню токен в git (только у себя в рабочей среде, в код сайта он НЕ попадёт);
- отправлю main на GitHub одной командой push;
- Cloudflare Pages увидит пуш и сам пересоберёт сайт за 1–3 минуты;
- после этого каждый мой следующий этап изменений будет улетать на сайт автоматически —
  тебе больше ничего нажимать не придётся.

## Почему это безопасно
- Токен даёт право только писать в репозитории магазина (scope `repo`).
- Ты можешь в любой момент отозвать его: https://github.com/settings/tokens → tik-push → Delete.
- В файлах сайта токена не будет никогда.

## Если не хочешь давать токен
Альтернатива на 3 минуты: зайди на https://github.com/stasikbobski-cloud/tik-online-store
и вручную обнови файлы из этой среды (открываешь файл → кнопка карандаша ✏️ →
вставляешь содержимое → "Commit changes"). Файлы для обновления: index.html, catalog.html,
cart.html, account.html, favorites.html, delivery.html, about.html, contacts.html,
payment.html, faq.html, returns.html, privacy.html, cooperation.html, shared.css,
info.css, shared-shell.js, STATUS.md. Но с токеном быстрее и надёжнее.
