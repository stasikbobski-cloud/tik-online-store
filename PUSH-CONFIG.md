# Как я пушу изменения автоматически (служебная заметка)

Токен GitHub выдаётся владельцем и хранится ЛОКАЛЬНО в этой рабочей среде
(файл ~/.git-credentials, права 600). В репозиторий и на сайт токен НЕ попадает.

Каждый раз после коммита выполняется:
    git push origin main

Cloudflare Pages сам замечает новый коммит в main и пересобирает сайт за 1-3 минуты.

Если пуш вдруг начнёт спрашивать логин/пароль — значит токен истёк или отозван.
Нужно выдать новый: https://github.com/settings/tokens/new?description=tik-push&scopes=repo
и прислать его в чат.
